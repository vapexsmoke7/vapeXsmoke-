
VapeXSmoke Complete Website
===========================

FEATURES
- Customer product catalogue
- Cart and online order form
- Orders saved in SQLite
- Admin login with your own password (first launch)
- Admin add products, images, prices and stock
- Admin view/update order status
- 50+ products supported (no fixed limit)
- Your supplied logo included
- Age/legal compliance notice

RUN
1. Install Node.js 18+.
2. Open a terminal in this folder.
3. Run: npm install
4. Run: npm start
5. Open: http://localhost:3000
6. Admin panel: http://localhost:3000/admin.html
7. On first admin visit, create your own password.

IMPORTANT
- This package is a starting production-style application, but a public deployment should use HTTPS,
  a strong SESSION_SECRET, secure cookies, backups, rate limiting, and a proper production database.
- Do not share database secrets or server credentials.
- Configure delivery, age verification, and product-sale rules according to the laws that apply to your business.
